# 0004: Reconciliation with Excel is a test

Date: 2026-11-05. Status: accepted.

Python and Excel are two independent calculations of the same method. a private test (kept off GitHub, as it needs the private data) values validation case 1 and compares every headline number (a, b, loss per year, R², value, SD, range, near-age average, known-price gap) and every comparable's adjusted price with the values Excel calculated and saved, to 9 decimal places. A release is not made unless it passes.
